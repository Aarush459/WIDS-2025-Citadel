WIDS 2025 – Build the Algorithmic Black Box

This repository contains my submission for WIDS 2025 – Citadel: Build the Algorithmic Black Box.

The project implements a simplified electronic market simulator focusing on the core mechanics of a limit order book–based exchange. The goal of this work is to understand market microstructure and build a correct, extensible simulation environment

What is implemented

Limit Order Book with separate bid and ask sides
Price–time priority matching
Support for limit orders and market orders
Event-driven simulation engine
Simple agent to generate order flow
Market analytics:
Bid–ask spread
Mid-price
VWAP
Volatility
Market visualisation:
Spread plot
Volatility plot
Candlestick chart

Notes
The focus of the project is on market infrastructure correctness, not trading profitability
The system is designed to be extended with learning-based agents in future work
